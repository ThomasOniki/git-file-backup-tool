= git-file-backup-tool

git-file-backup-tool is a tool written in bash that periodically checks to see if any registered repositories have been modified, and automatically creates commits using the date and time as the commit message that are then pushed to the origin remote.

== Installation

Run
[source,sh]
----
curl https://codeberg.org/ThomasOniki/git-file-backup-tool/raw/branch/main/install.sh | PREFIX="$HOME/.local" sh
----

or if have cloned the repo,
[source,sh]
----
bash install-cloned.bash
----

You can change the PREFIX variable to your prefered location.

== Configuration

The default configuration should be in $XDG_CONFIG_HOME/git-file-backup-tool/config.bash after the first installation.

== Uninstallation

Run
[source]
----
curl https://codeberg.org/ThomasOniki/git-file-backup-tool/raw/branch/main/uninstall.sh | PREFIX="$HOME/.local" sh
----

or if have cloned the repo,
[source,sh]
----
sh uninstall.sh
----

PREFIX should be set to the value you used when installing.

== Troubleshooting

On macos, the launch agent logs can be found in $XDG_STATE_HOME/git-file-backup-tool.log.
